How SupportSphere works

The life of a support ticket

  1. 1OpenYou raise a ticket. Edit or delete it until an agent is assigned.
  2. 2Agent assignedA manager assigns an agent whose expertise matches the category.
  3. 3ResolvedYou add a resolution summary and your satisfaction, then mark it resolved.
  4. 4ClosedThe manager closes the ticket. You can then leave a review.

Ticket lifecycle

Who does what in SupportSphere

  1. 1OpenA client raises a ticket with a title, description, priority and issue category.
  2. 2Agent assignedYou assign an available agent — suggestions match the agent’s expertise to the ticket category.
  3. 3ResolvedThe client adds a resolution summary and satisfaction status, then marks it resolved.
  4. 4ClosedYou close the ticket. The client can then review the agent.
